# 工作台主题 v1.2.0

适用于官方 DeepSeek Harness Web **0.1.7-rc.2**。主题通过官方 `theme.overrideTokens()` 设置共享明暗配色，提供 APTX 标志与可选的小哀展示组件。导航、文档和其他业务插件均可独立安装、启停；主题没有对某个业务插件的必需依赖。

设置 → 通用 → 外观保留原生明暗模式，集中提供展示素材、强度、标志和减少动态效果。“无装饰”关闭人物与分镜，保留配色；停用主题会释放配色层、标志、门户、设置行、观察器与监听器，恢复其他主题或官方默认。

```sh
dsh plugin --profile web add /path/to/dsh-workbench-theme-1.2.0.tgz --ignore-scripts
dsh web
```

使用 `DSH_HOME` 指定已授权的目标 Profile。移除使用 `dsh plugin --profile web remove dsh-workbench-theme` 后重启。主题不拥有、修改或删除文档、会话和业务数据。

升级或回退时先停止目标 Profile，备份配置并记录旧包版本与 SHA-256，再添加目标版本包并重启。主题偏好保存在宿主配置中；保留配置即可恢复。验证首页、插件页和已参与的 Shadow 页面，以及明暗、无装饰、减少动态效果、停用与重新启用；卸载后业务页面继续使用原生主题。

旧导航插件的 `workbench-shell` 配置保留为兼容读取入口。新设置保存于 `workbench-theme`：首次发现旧偏好时通过官方 ConfigForm 的原子、版本校验写入一次，随后只以新偏好为准。后装导航也可迁移；用户已在新主题中选择的设置优先。远程浏览器按官方规则仅保留本次连接的临时偏好。

接入规则见 [通用外观协议](docs/appearance-contract.md)。装饰代码仅识别通用位置，不读取业务插件身份、文件、会话、按钮或编辑器内容。官方首页与插件管理页的有限 DOM 适配单独绑定 rc.2，升级宿主时需重新核验。

```sh
npm ci --omit=peer
npm run build
npm run check
npm test
npm pack
```

素材来源与权利范围见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

新版按通用位置分配素材：插兜立绘用于欢迎区、电影分镜用于目录页头、彩稿用于侧栏、不同银箔用于助手与设置。插件页滚走页头后仅在充足的外侧留白显示小分镜；设置可以展开查看全部八种展示形式。点线标题只绘制 opt-in 的纯文本标题，受无装饰、减少动态效果、触屏与卸载控制；不改变原生输入或正文。

资料库通过通用 open Shadow 根声明参与装饰。标题旁使用小幅轻快银箔，原件空状态使用彩稿，无在线预览时使用边角立绘；三个位置保持不同素材和比例。图谱与正文区域保持完整，窄容器隐藏标题分镜。“无装饰”、根移除与主题停用会撤回该根内的 CSS 和门户，业务不需要依赖主题包。
